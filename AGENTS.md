# Repository conventions

Rules for all changes to this repository.

## Attribution

Nothing in this repository, or in anything published from it, may show which tools, assistants or automation were used to create the content. This includes:

- Code, code comments and file headers
- Commit messages and tags (no co-authorship or "generated by" trailers)
- Pull request and issue titles, descriptions and comments
- README.md, docs/, SCOPE.md, ROADMAP.md and every other documentation page
- fastlane/ store metadata (titles, descriptions, changelogs)
- App UI strings and resources
- Workflows, templates and badges

Write everything as if the maintainer wrote it by hand.

## Project rules

- Read CONTRIBUTING.md and SCOPE.md first. The app stays offline: no new internet access, tracking or permissions without a good reason.
- No emojis in the app; icons are vector drawables.
- New user-facing texts go into both `app/src/main/res/values/strings.xml` (English) and `values-de/strings.xml` (German). Other languages come through Weblate, not pull requests.
- Add a short changelog line for the next version in `fastlane/metadata/android/en-US/changelogs/` and `de-DE/changelogs/` (at most 500 characters per file).
- Run `./gradlew testGithubDebugUnitTest` before finishing a change.
