Since Us

Privacy policy for the app “Since Us”

Deutsche Version

Last updated: October 1, 2026

In short

Since Us stores all data only on your device. It sends no data to us or anyone else and contains no ads, tracking or analytics. The versions from Google Play and F-Droid have no internet access at all.

Updates (GitHub version only)

The version downloaded from GitHub asks the public GitHub API (api.github.com) once a day whether a newer version exists. No personal data is sent; GitHub receives the usual technical connection data such as your IP address (see GitHub's privacy statement). You can turn this off in Settings → Updates.

Only when you tap Install, the app downloads the new version from GitHub and hands it to Android's installer. Again, GitHub only receives the usual connection data.

What data the app uses

  • Names, optionally pronouns, and for every relationship a date (optionally with a time) that you enter to calculate your time together.
  • One photo that you choose. Through the Android photo picker the app only receives this one picture and stores a copy in the app's private storage. The app has no access to your other photos.
  • Moments you save: title, date, note and optionally a photo. Photos are stored as a copy in the app's private storage.
  • Settings such as notifications and their time.

The app never sends this data off your device.

Sharing

Only when you tap Share, the app creates a picture on your device and hands it to the app you pick in the Android share menu. What happens there is up to that app.

Notifications

Notifications for special days are calculated and shown directly on your device. No server or push service is used.

Backup

If you have enabled Android backup (Google backup), Android may include the app's data in that backup so it can be restored on a new device. This is controlled by Android and Google and is subject to their privacy policies. You can turn backup off in the Android settings.

With Settings → Save backup you can also save all app data including your photos as a file yourself. You choose where the file is stored (for example in your downloads or a cloud folder of your choice). The app does not upload the file anywhere. Keep it safe, because it contains your names, dates and photos.

With Back up automatically the app saves such a file once a week to a folder you pick once. The three newest automatic backups are kept there, older ones are deleted by the app. If the folder belongs to a cloud service, that service's terms apply.

Sync between phones

Under Settings → Sync you can pair your phone with another phone. One phone shows a QR code, the other scans it with the camera. The app only asks for camera permission for this; camera images are not stored. The QR code contains a random key that is only stored on the paired phones (not in backups).

When you tap Send sync, the app creates a file encrypted with this key (AES-256-GCM) containing names, relationships and moments with photos, and hands it to the app you choose in the share menu. Only paired phones can open it. The app itself uploads nothing and uses no server for this.

Deleting your data

In the app, Settings → Start over → Delete all data removes everything immediately. Uninstalling the app also deletes all data.

Children

The app is not directed at children under 13.

This website

This website is hosted on GitHub Pages. When you visit it, GitHub processes the usual technical data such as your IP address to deliver the pages (see GitHub's privacy statement). The website itself uses no cookies, no tracking and no external fonts or scripts.
